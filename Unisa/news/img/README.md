# Immagini delle news

Metti qui le immagini da mostrare nelle notizie (jpg, png, webp, gif).

1. Da GitHub apri questa cartella e clicca **Add file → Upload files**, trascina l'immagine e fai **Commit changes**.
2. Poi pubblica la notizia da **Actions → Pubblica una news**, scrivendo nel campo *Immagine* il nome del file (es. `quiz.jpg`).

Meglio immagini leggere (sotto i 500 KB, larghe circa 1200 px). L'immagine si vede nella notizia sul sito, non nella notifica.
